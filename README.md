# BlockCoin Mini App — Prototype v0.1

This is a local playable prototype of the BlockCoin Telegram Mini App concept.

## Run
Open `index.html` in a modern browser.

## Current features
- Pixel/block-inspired UI
- Tap-to-mine
- Coins
- Energy
- Local save with localStorage
- Mobile-first layout

## Next development
1. Telegram Mini App SDK / Telegram user authentication
2. Backend database and secure server-side coin accounting
3. Daily rewards, missions, referrals
4. Inventory/shop
5. Leaderboard
6. Anti-cheat/rate limiting
7. Production hosting and Telegram Bot integration

Important: coins in this prototype have no cash value and are not withdrawable.
